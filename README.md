# smrt-marketplace

Claude Code plugins by [smrtlabs](https://smrtlabs.ai). Institutional memory, engineering tools, and ops automation.

## Installation

Add this marketplace to your Claude Code configuration:

```json
{
  "pluginMarketplaces": [
    "https://github.com/smrt-labs/smrt-marketplace"
  ]
}
```

Then enable individual plugins:

```json
{
  "enabledPlugins": [
    "smrt-labs/smrt-marketplace:smrt"
  ]
}
```
